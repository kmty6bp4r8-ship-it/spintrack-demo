# SpinTrack Demo

SpinTrack is a radio and streaming automation platform for Mac. This demo lets you see what it can do without spending hours filling it with music and production elements.

The demo comes with a 200-song library, station IDs, promos and commercials. Open it and a full week of logs is scheduled for you, and music starts playing within seconds.

## Download

Go to the **Releases** section on the right side of this page and download the latest file. Apple Silicon and Intel Macs each have their own build, so pick the one that matches your Mac.

## Getting started

**Step 1.** Unzip the download if needed, then double-click "SpinTrack Demo" to launch it.

**Step 2.** That's it. There is no setup, no login and no folder to choose. SpinTrack opens with a week of music, IDs, promos and commercials already playing.

## What you can try

Move songs around, build and run logs, run CHART (the music scheduler), create templates, schedule days and try voice tracking.

In the demo the library is locked, so you cannot add, replace or delete music, commercials, IDs, imaging or promos.

## Starting over

Quit the app, delete the folder ~/Library/Application Support/SpinTrack Demo, and launch it again for a clean week.

## About the demo content

The music and commercials in the demo library were created with AI so that no copyrighted material is included. It is not meant to sound like a great station. It is meant to show what the platform can do.
